# Contributing to Quriousity V2

First off, thank you for considering contributing to Quriousity V2! It's people like you that make the open-source community such a great tool for learning and creating.

## 🚧 Project Status
**Note:** This project is under active development. We are **still finding bugs** and refining the experience. Your help in identifying and fixing these issues is invaluable!

## How Can I Contribute?

### Reporting Bugs
This section guides you through submitting a bug report. Following these guidelines helps maintainers and the community understand your report, reproduce the behavior, and find related bugs.

- **Check for existing issues:** Before opening a new issue, please search to see if the bug has already been reported.
- **Be specific:** Include as much detail as possible. What happened? What did you expect to happen?
- **Provide reproduction steps:** A step-by-step guide on how to see the bug yourself.
- **Environment info:** Mention your browser, OS, and if you're running it locally or on Vercel.

### Suggesting Enhancements
We are always looking for ways to make Quriousity better. If you have an idea:
- Explain why this enhancement would be useful to most users.
- Provide a clear description of the suggested feature.

### Pull Requests
1. **Fork the repo** and create your branch from `master`.
2. **Ensure the build passes:** Run `npm run build` before submitting.
3. **Follow the style:** Match the existing coding style (TypeScript, Tailwind v4, Lucide icons).
4. **Link the issue:** If your PR fixes a bug, please link to the issue.
